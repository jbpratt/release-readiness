- [shots.py](shots.py): full-page screenshots and card text of the app's pages; `--record FILE` saves the `/api/v1/` responses the shots read as JSON fixtures for `page.py`. Needs `pip install --user playwright && python3 -m playwright install chromium`.
- Mockups: a design on live data is a dev-only route, one entry in `web/src/mockups/index.tsx`, served at `/mockups/<path>` by `npm run dev` and `page.py` builds only. Shoot it with the dev server proxied at a backend: `cd web && RR_API_TARGET=http://127.0.0.1:8088 npx vite --port 5174 --strictPort`, then from the repo root in a second terminal `python3 dev/shots.py --width 1440 --width 420 http://localhost:5174 /tmp/shots /mockups/<path>`.
- [compare.py](compare.py): before/after shots side by side with numbered boxes on what changed, or a titled contact sheet of any number of shots, one composite PNG per JSON spec (format in its docstring). Needs playwright, as `shots.py` does.
- [a11y.py](a11y.py): measured contrast of text and status icons, 24px targets, horizontal overflow and console errors per page, width and theme, from the running page's computed styles; exits 1 on any failure. Needs playwright, as `shots.py` does.
- [page.py](page.py): one self-contained HTML file of an app page or mockup on `shots.py --record` fixtures, for the design gallery: a `vite build --mode page` with JS, CSS, fonts and fixtures inline, people's names and sync errors scrubbed; refuses output holding a secret shape or over 16 MiB. Usage in its docstring.
