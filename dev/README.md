- [shots.py](shots.py): full-page screenshots and card text of the app's pages. Needs `pip install --user playwright && python3 -m playwright install chromium`.
- Mockups: a design on live data is a dev-only route, one entry in `web/src/mockups/index.tsx`, served at `/mockups/<path>` by `npm run dev` only. Shoot it with the dev server proxied at a backend: `cd web && RR_API_TARGET=http://127.0.0.1:8088 npx vite --port 5174 --strictPort`, then from the repo root in a second terminal `python3 dev/shots.py --width 1440 --width 420 http://localhost:5174 /tmp/shots /mockups/<path>`.
